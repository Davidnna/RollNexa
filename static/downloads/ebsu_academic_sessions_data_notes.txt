# EBSU academic session starter CSV — source notes

## What is included
The CSV contains four rows:
- 2025/2026 — First and Second semesters
- 2026/2027 — First and Second semesters

These are candidate academic-session records, not a verified statement of the current undergraduate teaching session.

## Sources
- EBSU 2025/2026 Post-UTME notice: https://ebsu.edu.ng/2025-2026-post-utme-application-screening/
- EBSU 2026/2027 Post-UTME notice: https://ebsu.edu.ng/2026-2027-post-utme-application-screening/
- EBSU 2026/2027 postgraduate admissions notice: https://ebsu.edu.ng/postgraduate-admissions-for-2026-2027-academic-session/
- EBSU academic calendar page: https://ebsu.edu.ng/academic-calendar/

The EBSU academic calendar page currently surfaces an academic calendar for 2023/2024. The admission notices establish that EBSU uses the 2025/2026 and 2026/2027 session labels for admission activities, but they do not establish the dates of the undergraduate teaching sessions or semesters.

## Important
- Session and semester dates are intentionally blank.
- No session or semester is marked current in the CSV.
- After importing, consult the current approved EBSU academic calendar or Registrar's notice.
- In RollNexa, use Set current on the verified session. Then set the current semester if applicable.
- The course catalogue CSV uses CURRENT and will resolve to whichever active session the administrator marks current.

The CSV does not assert that either session is the current undergraduate teaching session. The administrator must confirm the active session against the current approved academic calendar or an official Registrar notice before using Set current.

The page titled 2026/2027 Post-UTME includes body text that refers to 2025/2026. It is therefore not used as definitive evidence of the current undergraduate teaching session. The 2026/2027 postgraduate admission notice independently uses the 2026/2027 session label, but that does not establish the undergraduate academic calendar.
