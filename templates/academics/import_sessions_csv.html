IMPORT RULES

How session records are handled

academic_sessionUse YYYY/YYYY, for example 2026/2027. The ending year must be exactly one year later.
semesterUse FIRST, SECOND or SUMMER. Each session may have one row per semester.
Session and semester datesUse YYYY-MM-DD. Leave dates blank if the official dates have not been confirmed.
source_url, source_noteOptional provenance columns retained in the CSV for review.
Important: Imported sessions and semesters are created as active, but none is automatically marked current. This prevents RollNexa from selecting an academic session without administrator confirmation.
Safe import: The importer previews records, runs the final import in one transaction, does not delete records and does not overwrite existing dates. Re-uploading matching records is safe.
