CSV FORMAT

Supported columns

faculty_code, faculty_nameRequired on every populated row.
department_code, department_nameProvide both values together, or leave both blank.
programme_code, programme_nameProvide both values together. A programme must have a department.
award, duration_years, modeOptional. Unknown awards and durations should remain blank.
source_url, source_session, verification_status, notesOptional provenance columns. These are retained in the CSV for reference but are not stored as academic records.
Import behaviour: The importer creates missing records and updates matching records using their codes. It never deletes records, never deactivates existing records and never clears an existing award or duration when the CSV leaves those optional fields blank.
