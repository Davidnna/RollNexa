How the columns work

faculty_code, department_codeIdentify the department that owns the master course record.
course_code, course_title, credit_unitsMaster course identity. Credit units in each CSV row belong to that programme-specific offering, and may differ for the same course code in another programme.
stress_codeProgramme-specific curriculum classification: C, R, E, G or AR. It is stored on the offering, not the master course.
programme_code, academic_session, semester, levelIdentify the programme-specific offering. Use CURRENT for the session marked current in RollNexa.
offering_active, registration_open, max_studentsImported offerings remain closed for registration. Open registration manually after review.
description, source_url, source_noteOptional reference fields. Source notes remain in the CSV and are not treated as course descriptions.
Before upload: Ensure the faculty, course-owning departments, target programme, current academic session and its First/Second semester records already exist and are active. If no current session exists, import academic sessions and semesters first, then set the verified session as current.
Safe import: The importer previews records first, runs the final import in one transaction and does not delete or overwrite existing courses or non-empty offering provenance. Re-uploading the same file is idempotent; blank provenance fields on existing offerings may be filled from the CSV. New offerings have registration closed.
